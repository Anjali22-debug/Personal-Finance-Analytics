# 📊 Personal Finance Analytics

## 📌 Project Overview
This project analyzes personal financial transaction data to understand income, expenses, spending behavior, and savings trends over time.

The goal is to demonstrate a complete data analytics workflow — from raw data to actionable insights — using Python and pandas.

---

## 🎯 Objectives
- Clean and preprocess messy financial transaction data  
- Analyze income vs expense trends over time  
- Identify top spending categories  
- Evaluate monthly savings behavior  
- Generate summary reports for decision-making  

---

## 🔄 Project Pipeline

### 1️⃣ Data Profiling
- Inspected raw data structure
- Identified missing values, duplicates, and data type issues

### 2️⃣ Data Cleaning
- Parsed mixed date formats
- Handled missing and invalid values
- Standardized columns and data types
- Saved a cleaned dataset for reuse

### 3️⃣ Exploratory Data Analysis (EDA)
- Overall income vs expense comparison
- Monthly income and expense trends
- Category-wise expense analysis
- Monthly savings calculation and visualization

## 🔑 Key Insights
- Income consistently exceeds expenses across most months, indicating positive cash flow  
- Spending is dominated by fixed categories such as food and rent  
- Expense patterns show seasonal spikes  
- Monthly savings remain positive overall with some volatility
